## Scope and data protection

This is a source update, not a station-data migration. It does not delete or rewrite production media, channel assignments, commercial inventory, Kids approvals, artwork, profiles, PINs, favourites, watchlists, or playback history. The broadcast scheduling algorithms are retained.

The reference review found no demonstrably unused application files to delete. Static logos and source portraits are retained because saved programming may reference their public URLs. The service worker is loaded by URL and must not be treated as an unused module. Next.js routes, components, styles, tests, and assets remain in their required project structure. The update is distributed as one Git bundle.

## Release procedure

Import the bundle into the existing `retro-tv` repository, then push the included cleanup branch to GitHub. The workflow runs the regular Chromium, Firefox, WebKit, Android, iPhone, tablet, and television projects. Review that branch's CI and preview before merging to `master`.

Real AirPlay/Google Cast/Roku receivers, physical iOS/Safari behavior, production storage permissions, and live media reachability still need deployment/device verification. This update cannot establish universal device compatibility or guarantee that every externally hosted video is playable.

No automatic production deployment or database/storage mutation is included in the bundle. Git retains the base release for rollback.
